# Project P

A cozy pixel-art pet game built in Godot, targeting Android, iOS and desktop. You raise an original creature through growth stages, care for it, and battle with stats earned from real-life activity.

## Repository layout

| Folder | What lives here |
| --- | --- |
| [`art-and-sprites/`](art-and-sprites/) | Art style guide, 64x64 pet sprites, UI and environment art, source files |
| [`claude-skills/`](claude-skills/) | Claude skills used to speed up development (sprite specs, Godot helpers, planning) |
| [`godot-code/`](godot-code/) | The Godot project: scenes, scripts, exported assets |
| [`dev-plan/`](dev-plan/) | Game design notes, progression systems, roadmap and milestones |
